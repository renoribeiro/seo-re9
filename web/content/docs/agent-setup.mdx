O RE9 SEO conecta seu agente a dados de SEO em tempo real por meio do MCP. As skills dão ao agente fluxos de trabalho reutilizáveis para pesquisa de palavras-chave, auditorias, pesquisa de concorrentes e outras tarefas de SEO.

## Configure seu agente

Copie este prompt no Claude Code, Codex, Grok Bot, Hermes ou outro agente. Ele pede que o agente use o método de instalação compatível e oriente você nas etapas que precisar fazer por conta própria.

<AgentPrompt kind="setup" />

Aprove o login do RE9 SEO no navegador quando for solicitado. Com a configuração concluída, peça ao agente para usar o **SEO Coach** (`seo-coach`) e ajudar você a escolher o próximo passo.

Você também pode copiar este prompt na [Configuração do agente no RE9 SEO](https://seo.agenciare9.com.br/ai). Em uma instância self-hosted, use a página de Configuração do agente dela, para que o prompt inclua o endereço do seu próprio servidor.

Prefere configurar por conta própria? Siga as instruções do seu agente abaixo. Se o prompt de configuração já concluiu a instalação, vá direto para [Atualize suas skills](#update-your-skills).

### Claude Code

Execute dentro do Claude Code para instalar o MCP e as skills públicas de SEO:

```text
/plugin marketplace add renoribeiro/seo-re9
/plugin install openseo@openseo
```

Se o Claude pedir para ativar o plugin, execute `/reload-plugins`. Siga a solicitação de login e depois teste `/openseo:seo-coach`. Veja o [guia do plugin para Claude Code](/docs/claude-code-plugin) para resolver problemas.

### Codex CLI

Execute no seu terminal:

```bash
codex plugin marketplace add renoribeiro/seo-re9
codex plugin add openseo@openseo
```

Recarregue ou reinicie o Codex se o plugin ainda não estiver disponível e depois faça login:

```bash
codex mcp login openseo
```

Peça ao Codex para usar o SEO Coach. Veja o [guia do plugin para Codex](/docs/codex-plugin) para resolver problemas. Para plugins instalados por um diretório do aplicativo desktop, use os controles desse diretório.

### Hermes

Use o prompt de configuração acima para conectar o MCP. Para instalar o SEO Coach pelo hub de skills do Hermes, execute no seu terminal:

```bash
hermes skills install renoribeiro/seo-re9/plugins/openseo/skills/seo-coach
```

Repita com os nomes das outras [skills do RE9 SEO](/docs/skills) que você quiser. Instalações pelo hub guardam a origem, para que o Hermes possa verificar atualizações depois. Veja [gerenciamento de skills do Hermes](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills).

### Grok Bot

Cole o prompt de configuração no seu Bot. Abra **Marketplace** na barra lateral para gerenciar skills e conectores empacotados. As skills privadas ficam em **Your plugins → Manage plugins and skills → Private skills**. Skills privadas são compartilhadas entre todos os seus Bots.

Siga as instruções do Bot para as etapas que você precisar concluir por conta própria. Veja [skills do Grok Bot](https://docs.x.ai/grok-bot/skills-routines-and-automations).

### Claude web/Desktop e outros agentes

Siga o [guia de conexão MCP](/docs/mcp) e depois instale as skills pelo gerenciador de skills compatível com o seu agente. O Claude web/Desktop gerencia skills personalizadas em **Customize → Skills**; esse fluxo é diferente do plugin para Claude Code.

Para agentes que usam a CLI de skills, escolha as skills públicas do RE9 SEO de forma interativa:

```bash
npx skills add https://github.com/renoribeiro/seo-re9/tree/main/plugins/openseo/skills
```

Escolha o agente atual e o escopo de instalação que preferir. Pule esta etapa se o plugin do RE9 SEO já fornece suas skills. Veja a [configuração manual de skills](/docs/skills/setup) para outras opções.

## Atualize suas skills [#update-your-skills]

Quando o RE9 SEO lançar skills melhoradas, atualize as cópias instaladas no seu agente. Atualizar só a conexão MCP não atualiza esses arquivos.

Cole este prompt no agente em que você usa o RE9 SEO. Ele pede que o agente verifique como as skills foram instaladas e preserve suas configurações de conexão e edições pessoais.

<AgentPrompt kind="update" />

Para atualizar manualmente, use o método que corresponde à sua instalação abaixo.

### Atualize o plugin do Claude Code

Execute dentro do Claude Code:

```text
/plugin marketplace update openseo
/plugin update openseo@openseo
/reload-plugins
```

Você pode ativar as atualizações automáticas em `/plugin` → **Marketplaces** → **openseo** → **Enable auto-update**. Em marketplaces de terceiros, essa opção vem desativada por padrão. Recarregue quando o Claude pedir para ativar uma atualização. Veja a [documentação de atualização de plugins do Claude](https://code.claude.com/docs/en/discover-plugins#configure-auto-updates).

### Atualize o plugin do Codex CLI

Execute no seu terminal:

```bash
codex plugin marketplace upgrade openseo
```

Recarregue ou reinicie o Codex se as skills atualizadas não estiverem disponíveis. Se a sua CLI rejeitar um comando, confira `codex plugin --help` para ver os comandos aceitos pela sua versão. Veja a [documentação de marketplace da OpenAI](https://developers.openai.com/plugins/build/plugins).

### Atualize as skills do hub do Hermes

Verifique se há atualizações e depois atualize cada skill do RE9 SEO instalada pelo nome. Por exemplo:

```bash
hermes skills check
hermes skills update seo-coach
```

Repita para as outras skills do RE9 SEO instaladas. Por padrão, o Hermes ignora skills editadas localmente. Revise essas edições antes de substituí-las; só adicione `--force` se quiser descartá-las. Veja o [ciclo de atualização do Hermes](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills#update-lifecycle).

### Atualize skills instaladas com a CLI de skills

Liste suas instalações e depois atualize as skills do RE9 SEO pelo nome. Por exemplo:

```bash
npx skills list
npx skills update seo-coach seo-audit
```

Use os nomes que você realmente instalou e escolha o mesmo escopo, de projeto ou global. Passe `-g` para skills globais ou `-p` para skills de projeto. Faça backup das edições pessoais antes de atualizar. Execute o comando de configuração separadamente para selecionar fluxos de trabalho adicionados recentemente. Veja a [documentação da CLI de skills](https://github.com/vercel-labs/skills#skills-update).

### Atualize o Grok Bot ou skills copiadas manualmente

Use o prompt de atualização acima. No Grok Bot, abra **Marketplace → Your plugins → Manage plugins and skills** para encontrar a skill ou o plugin instalado. A documentação pública dele ainda não especifica um comando para atualizar skills a partir da origem, então use os controles de gerenciamento disponíveis na sua versão.

Para skills copiadas manualmente, compare as cópias instaladas com as [pastas públicas de skills do RE9 SEO](https://github.com/renoribeiro/seo-re9/tree/main/plugins/openseo/skills). Preserve as edições pessoais e substitua a pasta inteira da skill, incluindo os arquivos de apoio. Para skills enviadas por upload, use o gerenciador de skills do seu agente, como **Customize → Skills** no Claude.

Depois de atualizar, recarregue as skills ou inicie uma nova sessão, se necessário. Peça ao agente para confirmar que encontra as skills atualizadas do RE9 SEO antes de começar sua próxima tarefa de SEO.
