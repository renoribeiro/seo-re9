A skill de relatório de SEO (`seo-report`) é a forma como os outros fluxos do RE9 SEO entregam a você o trabalho pronto.

Você não a executa sozinha. Quando o agente termina uma auditoria, um estudo de palavras-chave ou uma análise de concorrentes, esta skill diz a ele como escrever o resultado em uma página HTML autocontida e salvá-la no seu projeto. A página aparece na página Relatórios do projeto no RE9 SEO, onde qualquer pessoa da sua equipe pode abri-la, lê-la no celular e imprimi-la em PDF.

## O que esta skill ajuda seu agente a fazer

- Escrever uma página HTML em vez de um paredão de texto no chat, usando um modelo inicial compartilhado para que todos os relatórios tenham a mesma aparência.
- Salvá-la no projeto com `save_report`, para que fique vinculada ao site analisado e seja fácil de encontrar depois.
- Consultar `list_reports` primeiro e atualizar o relatório existente quando estiver corrigindo a própria execução, em vez de deixar você com três cópias quase idênticas.
- Manter o relatório autocontido: todo o estilo fica dentro do arquivo, nada é buscado na web e ele imprime corretamente mesmo sem conexão.
- Escrever um resumo curto junto com a página, para que o agente, ou o próximo agente, possa retomar o trabalho sem reler o relatório inteiro.
- Explicar o benefício esperado ao lado de cada recomendação, diferenciando resultados medidos de estimativas e hipóteses.
- Responder no chat com o link, o veredito e a recomendação principal com o benefício esperado, quando houver base para isso.

## O que você recebe

Uma página de relatório no seu projeto com um título como "Panorama competitivo — 17 de set. de 2026". Os títulos incluem a data completa do relatório e omitem o site do projeto. Um relatório sobre outro site inclui esse domínio para deixar claro o assunto; o mesmo vale para um relatório em um projeto sem site definido. Abra-o pela página Relatórios na barra lateral. O menu ao lado dele exporta um PDF, abre o relatório em tela cheia ou em uma aba separada.

Relatórios não consomem créditos, e não há um limite prático de quantos um projeto pode ter. A página Relatórios mostra os 100 mais recentes.

## Compartilhar um relatório

Em seo.agenciare9.com.br, abra um relatório, clique em Compartilhar e ative o Link público. Envie o link para um cliente ou colega de equipe; a pessoa não precisa de uma conta no RE9 SEO. O link sempre mostra a versão salva mais recente e não é indexado por mecanismos de busca. Desative a opção e o link deixa de funcionar, bloqueando novos visitantes em até um minuto.

## Como obter o melhor resultado

- Peça um fluxo de trabalho, não um relatório: "audite badseo.dev" já gera um relatório por conta própria.
- Se quiser que o relatório seja corrigido em vez de duplicado, diga isso, e o agente vai atualizar a mesma página.
- Diga para quem é o relatório. O agente coloca essa informação na assinatura e ajusta a linguagem ao público.
- Relatórios não têm histórico de versões nem opção de desfazer, então uma correção sobrescreve o que havia antes.

## Modelos de relatório

Um modelo é um briefing reutilizável para um tipo de relatório: para quem ele é, quais seções tem e em que ordem, qual deve ser o tom e como deve ser a assinatura. Crie um na página Modelos, acessada pela página Relatórios do seu projeto. Os modelos pertencem a um projeto; para reutilizar um modelo em outro lugar, peça ao agente para listá-lo no primeiro projeto e salvar uma cópia no segundo.

O agente vê os modelos de um projeto e segue um deles quando você o menciona pelo nome ou quando pede o tipo de relatório que ele descreve ("escreva o resumo de auditoria para cliente de badseo.dev"). Um simples "audite este site" continua usando o formato próprio da skill. O modelo substitui as seções e o tom; ele nunca muda a forma como a página é construída, então o relatório continua imprimindo e abrindo no celular.
