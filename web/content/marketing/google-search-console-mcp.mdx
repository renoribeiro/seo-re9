A maioria dos servidores MCP do Google Search Console (GSC) é open source, mas dá bastante trabalho configurar. Você precisa criar um projeto no Google Cloud, ativar uma API, criar um cliente OAuth, baixar um `credentials.json` e manter um servidor local rodando. O RE9 SEO cuida da conexão com o Google para você. Você cria sua conta, conecta sua propriedade e começa a perguntar.

## Configuração: sem projeto no Google Cloud

1. Crie sua conta no RE9 SEO.
2. Siga os primeiros passos. Quando for solicitado, clique na opção para conectar o Search Console e escolha sua propriedade.
3. Adicione o endpoint MCP do RE9 SEO ao seu cliente (passos abaixo) e aprove o login do RE9 SEO quando for solicitado.

A URL do servidor MCP hospedado é:

```txt
https://seo.agenciare9.com.br/mcp
```

### Claude Code

```bash
claude mcp add --transport http --scope user openseo https://seo.agenciare9.com.br/mcp
```

### Claude Desktop

1. Abra Customize → Connectors.
2. Clique em **Add** (ou **+**) e escolha **Add custom connector**.
3. Cole `https://seo.agenciare9.com.br/mcp`.

### Cursor

1. Abra Cursor Settings → Tools & Integrations → MCP Tools.
2. Clique em **New MCP Server** (isso abre o `mcp.json`) e adicione:

```json
{
  "mcpServers": {
    "openseo": {
      "url": "https://seo.agenciare9.com.br/mcp"
    }
  }
}
```

### Codex CLI

```bash
codex mcp add openseo --url https://seo.agenciare9.com.br/mcp
```

Qualquer outro cliente MCP funciona do mesmo jeito: adicione `https://seo.agenciare9.com.br/mcp` como servidor remoto e faça login. A configuração completa e a solução de problemas estão na [documentação do MCP](/docs/mcp).

### O jeito "faça você mesmo" (todos os outros MCPs do GSC)

1. Criar um projeto no Google Cloud
2. Ativar a Search Console API
3. Configurar a tela de consentimento OAuth
4. Criar as credenciais do cliente OAuth
5. Baixar o `credentials.json`
6. Instalar e rodar um servidor MCP local

## O que perguntar de verdade

- "Para quais consultas estou na página dois e perto de chegar à página um?"
- "Mostre as páginas em que as impressões subiram, mas os cliques ficaram estáveis. Provavelmente é um problema de título ou meta description."
- "Algum post do meu blog está competindo com outro pela mesma consulta?"
- "A página `/precos` está indexada? Se não, o que está bloqueando?"
- "Quais consultas mais perderam cliques nos últimos 28 dias?"

## O que o seu agente pode ler

São duas ferramentas somente leitura sobre a propriedade que você conectar. As duas trazem os números do próprio Google, e nenhuma consome créditos.

**Desempenho na busca.** Cliques, impressões, CTR e posição média do seu site, com recortes por consulta, página, país, dispositivo e data. Consulte até 16 meses de histórico em uma única pergunta.

**Inspeção de URL.** Se uma página está indexada e, se não estiver, por quê: status de cobertura, último rastreamento, a canônica escolhida pelo Google em comparação com a que você declarou, além das verificações de Mobile e de resultados avançados. Até 10 URLs por vez.

O agente pode ler e inspecionar. Ele não pode alterar nada na sua conta.

## Créditos e custos

As ferramentas do Search Console não consomem créditos: o Google não cobra para você ler os seus próprios dados, então lê-los pelo RE9 SEO nunca gasta uso. Elas fazem parte do plano do RE9 SEO, junto com as ferramentas baseadas em créditos (pesquisa de palavras-chave, monitoramento de posições, backlinks), que funcionam pelo mesmo endpoint MCP. ## Perguntas frequentes

### Quanto custa?

As ferramentas MCP do Search Console fazem parte do plano do RE9 SEO e não consomem créditos. As outras ferramentas do RE9 SEO (pesquisa de palavras-chave, monitoramento de posições, backlinks) usam os créditos de uso do plano, pelo mesmo endpoint. Para condições do plano hospedado, fale com a gente: [trafego@re9.online](mailto:trafego@re9.online). Hospedar por conta própria não tem custo de licença.

### É open source?

Sim. O RE9 SEO é open source, então você pode hospedar tudo por conta própria, incluindo o MCP do Search Console. A conexão com um clique usa o app Google hospedado do RE9 SEO. Se você hospedar por conta própria, vai usar seu próprio cliente OAuth do Google, justamente a etapa no console do Cloud que a versão hospedada evita. Hospedado significa zero configuração; hospedagem própria significa controle total.

### É somente leitura?

Sim. O RE9 SEO solicita acesso somente leitura (`webmasters.readonly`). Seu agente pode ler dados de desempenho e inspecionar URLs, mas não pode alterar sua conta.

### Quais clientes de IA funcionam?

Qualquer cliente MCP, incluindo Claude Code, Claude Desktop, Cursor, Codex e OpenClaw. Adicione o endpoint MCP do RE9 SEO e faça login.

### Quão atualizados são os dados?

São os dados do próprio Google, então os dias mais recentes podem estar incompletos. O histórico vai até 16 meses atrás, igual à interface do Search Console.
