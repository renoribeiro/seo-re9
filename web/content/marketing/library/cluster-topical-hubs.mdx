## O que é agrupamento de palavras-chave?

Agrupamento de palavras-chave (keyword clustering) é reunir as palavras-chave que merecem a _mesma página_ porque compartilham uma única intenção. "Agrupamento de palavras-chave", "clusterização de palavras-chave" e "como agrupar palavras-chave para seo" formam um cluster, então ficam em uma página. "Melhor ferramenta de agrupamento de palavras-chave" é outra intenção, então fica em outra página. A unidade do SEO é o cluster, não a palavra-chave isolada.

## Como agrupar palavras-chave em hubs temáticos (sem uma ferramenta de US$ 99/mês)

1. **Comece pela sua lista expandida.** [Sementes](/library/keyword-research/seed-from-conversation) → [expansão](/library/keyword-research/long-tail-question-mining) → [rótulos de intenção](/library/keyword-research/search-intent-mapping). O agrupamento só compensa a partir de umas 100 linhas.
2. **Agrupe pela sobreposição de SERP, não pela semelhança das palavras.** Duas palavras-chave ficam juntas quando o Google já ranqueia as mesmas páginas para as duas. Agrupar por palavras em comum ("ferramenta de palavras-chave" + "keyword tool io") cria grupos falsos.
3. **Dê a cada cluster o nome da intenção dele.** Esse nome vira o título provisório da página. Se você não consegue nomear a intenção em uma linha, o cluster na verdade são dois.
4. **Organize os clusters em um hub.** O cluster do termo principal é a página pilar; cada cluster de subtema é uma página satélite que aponta para ela. Os links internos seguem a proximidade de intenção, não a ordem cronológica.
5. **Associe cada cluster a uma URL e registre isso.** O mapa de palavras-chave (uma planilha simples: cluster → URL → status) é o documento que evita canibalização no futuro.

## Como resolver a canibalização de palavras-chave

A canibalização é o problema oposto: duas páginas suas disputam a mesma intenção, o Google alterna entre elas e as duas ranqueiam pior do que qualquer uma ranquearia sozinha.

- **Encontre:** no [Search Console](/google-search-console-mcp), agrupe por consulta + página. Qualquer consulta em que 2 ou mais URLs suas se revezam nas impressões é candidata. A [descoberta programática](/library/keyword-research/gsc-programmatic-discovery) faz o mesmo agrupamento em todas as páginas de uma vez.
- **Resolva:** junte a página mais fraca à mais forte (redirecionamento 301) ou reaponte a página mais fraca para uma intenção realmente diferente e mude o título dela.
- **Previna:** use o mapa de palavras-chave do passo 5. Nenhuma página nova vai ao ar sem verificar qual cluster ela ocupa.

Rode este fluxo com o [MCP do RE9 SEO](/docs/mcp):

```text
Usando o MCP do RE9 SEO + o Search Console: puxe minhas consultas
agrupadas por consulta e página, sinalize as consultas em que duas
URLs minhas se alternam e proponha correções de
fusão/redirecionamento. Depois, agrupe as palavras-chave que
pesquisei por intenção comum e gere um mapa de palavras-chave
cluster → URL.
```

## Perguntas frequentes sobre agrupamento de palavras-chave

### Qual é a melhor ferramenta de agrupamento de palavras-chave?

Para agrupar por sobreposição de SERP em grande escala, existem ferramentas pagas, mas, para a maioria dos sites, a pesquisa do RE9 SEO + uma etapa de agrupamento por intenção (o prompt do MCP acima) resolve. Avalie as ferramentas pelo critério de agrupar ou não por sobreposição de SERP; agrupar por semelhança de palavras é brinquedo.

### Existe ferramenta gratuita de agrupamento de palavras-chave?

Não uma ilimitada. A etapa de agrupamento em si é gratuita (o prompt do MCP acima faz isso), mas ela roda sobre palavras-chave pesquisadas, e dados de palavras-chave de qualidade são a parte que custa dinheiro em qualquer lugar. O RE9 SEO inclui a etapa de agrupamento junto com a pesquisa, então não há uma ferramenta de agrupamento separada para comprar.

### O que é um modelo de mapeamento de palavras-chave?

Uma planilha com uma linha por cluster: palavra-chave principal, palavras-chave de apoio, intenção, URL de destino e status. O mapa de palavras-chave acima é o exemplo prático; copie a estrutura. Acrescente uma coluna de previsão e ela vira uma ordem de produção: [dimensione cada cluster](/library/keyword-research/opportunity-sizing-forecasting) antes de comprometer o trimestre.
